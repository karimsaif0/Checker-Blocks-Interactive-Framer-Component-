## Customize in Framer

Checker Blocks is designed to be controlled directly from Framer's property panel.

**Preset** selects a ready-made visual system or unlocks Custom mode.

**Background** and **Pattern** define the two-color palette.

**Cell Size** controls the scale and density of the grid in Custom mode.

**Large Blocks** controls how often neighboring cells merge into larger 2×2 compositions.

**Animate** enables or disables the automatic rhythmic transformations.

**Speed** controls animation playback speed in Custom mode.

**Change** controls how much of the grid is likely to transform on each beat.

**Interaction** enables pointer-driven changes.

**Seed** generates a different starting composition while keeping that composition deterministic across renders.

## Built for Framer

The component includes responsive width and height support, Framer property controls, `useIsStaticRenderer()`, reduced-motion handling, ResizeObserver-based resizing, IntersectionObserver-based off-screen pausing, animation-frame cleanup, and a capped device pixel ratio for better performance.
